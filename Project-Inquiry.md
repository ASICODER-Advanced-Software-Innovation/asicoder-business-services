## How to Submit a Project Inquiry

### Step 1 — Open the Inquiry Page

Visit:

https://www.asicoder.co.uk/project-request

### Step 2 — Sign In or Create an Account

The current project request page asks users to create an account or sign in before submitting the request.

### Step 3 — Enter Your Details

The inquiry form requests:

- Full name
- Email address
- Phone number
- Company name, if applicable

Provide accurate contact information so ASICODER can discuss the inquiry.

### Step 4 — Select Your Service

Choose the relevant project or service type.

### Step 5 — Describe the Budget and Timeline

Provide an estimated budget and preferred deadline where possible.

These details help with project scoping but do not establish a guaranteed price or delivery date.

### Step 6 — Explain the Requirements

Describe:

- The problem you want to solve
- The intended users
- Required features
- Supported platforms
- Existing software, if applicable
- Desired integrations
- Expected outcomes

### Step 7 — Attach Supporting Information

The page currently supports optional attachments such as PDF, DOC, DOCX, JPG, PNG and ZIP, with a displayed maximum file size of 1 MB.

Do not upload passwords, private keys, API secrets or unnecessary personal data.

### Step 8 — Submit the Inquiry

Submit the requirements for review.

The ASICODER team can then discuss relevant scope, pricing, next steps and delivery arrangements.

## What Makes a Good Project Brief?

A helpful project brief should include:

| Requirement | Example |
|---|---|
| Project type | Custom Laravel web application |
| Business goal | Manage bookings and customer requests |
| Users | Admin, staff and customers |
| Key features | Login, dashboard, booking, email notifications |
| Integrations | Email service, approved payment provider |
| Platform | Responsive web application |
| Existing code | Laravel project or new development |
| Budget | Approximate planned range |
| Deadline | Preferred completion timeframe |
| Deliverables | Agreed code, deployment or documentation |

These examples illustrate how to describe a project, not a fixed ASICODER product package.

## Frequently Asked Questions

### Can I request a new Laravel application?

Yes. You can submit requirements for a new Laravel or PHP development project.

### Can ASICODER improve an existing React application?

Existing React projects can be reviewed for supported improvements, integrations and bug fixes.

### Can I request an AI chatbot?

Yes. Describe your intended users, business context, integrations and desired capabilities.

### Can I request just one feature or bug fix?

Yes. A custom inquiry can describe a limited development task as well as a larger project.

### Is a submitted inquiry automatically accepted?

No. Scope, feasibility, availability, pricing and terms need to be reviewed.

### Can I monitor project progress?

The website describes customer dashboard functionality for relevant project updates, messages, payment requests and working-process information.

### Does the form guarantee my preferred deadline?

No. Delivery commitments depend on review and the agreed project proposal.
